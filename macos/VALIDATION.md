## 本轮实际验证

- C# Core：64 项离线检查通过，在本机 macOS 运行。
- Swift：44 项测试通过（35 项协议／核心／布局测试 + 9 项应用状态回归），警告视为错误；包括 18 型号、60 组无线样本、宏、备份校验、连续读、保留槽、写入间隔、取消和遇错停止。真实回调发现的非零 Data 起始索引已加入回归测试。应用状态覆盖断连保留草稿、保存不等于应用、离线草稿库、型号重置、忙碌/录制保护、扫描失败恢复、重复设备选择、无变化扫描不触发观察更新、空宏库与保留键禁止绑定。
- 实机：Apple Silicon / macOS 27.2，K87 经 USB 接收器使用 2.4G；设备信息与原始回包仅在本地保存。
- 双次全量读取一致。真实写入仅经用户授权执行亮度 `3→4→3`、休眠原始值 `6→10→6`（3→5→3 分钟）、Default.Scroll `→F1→原始四字节值`。
- 每项测试后，全量比较全部已解析字段，均与原始备份一致。比较包含非当前灯效、保留数组、三层所有按键槽；仅排除已校验的协议头 `space0`。
- 这些结果证明上述字段的配置往返，不代替实际灯光观感和操作系统按键行为测试。
- 打包 GUI 首次访问 HID 被 macOS 输入监控权限拦截。界面修整期间，测试构建曾在窗口中报告 K87 双次完整读取一致、电量 100%；最终安装到 `/Applications` 的 0.1.1 build 3 仍被输入监控拦截，因此最终安装版的 GUI 实机读写未通过验收。未修改系统权限。CLI 运行所在环境已有权限，其结果不能替代最终 GUI 验证。

## 仍需验证或不属于 Windows 已完成功能的部分

USB 有线的真实报告口径、全量设备恢复、真实宏库上传及触发、实际灯光和键值行为、断连中途取消、其他型号及音频设备、Intel 和旧版 macOS、Developer ID 签名/公证尚未完成实机验收。

音乐/GIF、云模板、固件升级、多设备灯效同步、程序关联切换及 C-Media/THX 内核 DSP 原本就没有在当前 Windows 客户端完成，未把它们记为本次已移植功能。蓝牙也未覆盖。无线接收 checksum 和 ACK 末字节规则沿用已审查 C# 行为，不增加猜测性校验。

## 0.1.1 界面重做与逻辑修整

- 整个界面层重新组织：原生功能侧栏、左上角设备菜单、固定工具栏和底部状态栏。六个键盘页面、设置窗口和音频面板统一原生控件、标题层级和间距；macOS 26+ 使用 Liquid Glass，旧系统保留原生兼容样式。
- 键盘图按 Windows 已有规则计算语义行首、缩进和真实键高，修复 X75/G75 换行和 K99/G98 数字区双行键。新增 4 项布局回归，覆盖全部 18 型号键框无重叠、边界及关键型号锚点；另导入 X75、K99 的离线对照配置检查实际窗口，K99 双行回车键坐标点击正确。
- 取消顶部重复导航和大面积装饰卡片。灯光参数对齐，性能采用自适应两栏，宏改为紧凑事件编辑表，配置改为原生文件列表，诊断高级报文默认收起。
- 设备菜单承载可能触发草稿确认的设备切换，功能侧栏仅切页，避免原生 List 选择回调里同步弹窗造成选中抖动。每秒无变化扫描不再发布观察更新。
- 侧栏展开／收起使用原生 balanced 分栏，主内容保持左对齐并统一解析动画几何；键盘保留固定坐标、整体缩放，避免逐键改变玻璃形状与动画终点再次居中。检查了按键页、性能页两种侧栏状态及缩放后键帽的坐标点击；未进行逐帧动画性能采样。
- 逐页检查了浅色、深色、侧栏整行选择、宏与逐键 RGB 布局、原生设置窗口。既有离线编辑、宏录制、配置保存/载入仍保留，数据路径不变。
- 增加刷新／导出快捷键 ⌘R／⌘S。扫描失败不终止检测；断开设备、读取失败、诊断失败和宏上传失败保留草稿，只清设备验证状态。
- 修复跨型号导入后返回 K87 预览的 schema、导出文件名和配置库更新；修改后的草稿不附带与其不匹配的原始回包。
- 灯效颜色随当前灯效和所选键同步；自定义灯效隐藏不存在的多彩字段；休眠保留半分钟原始值。
- 宏事件编辑使用索引保护，空宏库和保留键禁止绑定；宏录制回调延后到主线程下一次调度，避免 NSView 更新中修改 SwiftUI 状态。增加未保存宏提示、导入替换和退出保护。
- 音频共享全局忙状态，阻止写入途中切换设备和退出；请求 UUID 防止旧回调覆盖新状态，设置后重新读取。无音频设备实测。
- 修复旧 Swift 编译器对 `Data.init` 的歧义；CI 增加 Xcode 16.4 回退测试，新产物明确选择 Xcode 26.3。

本次 UI 重做没有增加 K87 设置写入，也没有修改输入监控授权。此前三项 CLI 实测结果仍保留；界面检查不作为额外硬件验收。
